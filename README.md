# Aether — Premium Minimalist Multivendor Marketplace

Simple, elegant white-label multivendor marketplace demo.

## Features
- Clean minimalist premium design
- Product listing & detail pages
- Vendor storefronts
- Vendor Dashboard
- Admin overview
- Cart (demo)
- Fully responsive

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Inter font

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## White-Label Notes
- Change name, colors, and branding in `src/app/layout.tsx` and `globals.css`
- Replace Unsplash images with your own
- Extend with real backend (auth, payments, commissions) as needed

Built as an enterprise-style prototype with a quiet, premium aesthetic.
